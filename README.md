## ⇢ About Me

Security researcher blending **red-team offense** with **blue-team discipline**. Currently working as a **cybercrime/security intern with Rajasthan Police**, where I built an Android digital-forensics framework used in active casework. Focused on SOC automation, digital forensics, and network security — approaching every system with both an attacker's instinct and a defender's foresight.

- 🛡️ **Blue-team**: alert triage, SIEM tuning (Wazuh, Splunk), MITRE ATT&CK mapping, log correlation, digital forensics
- 🔴 **Red-team roots**: recon automation, packet crafting, cryptography tooling, endpoint detection research
- 🤖 **Automation-first**: Python · Go · Rust pipelines, n8n integrations, VirusTotal enrichment workflows

| Project | Stack | Description |
|---|---|---|
| [**ThreatGrid**](https://github.com/rootwithkhandal/ThreatGrid) | Go | Real-time threat map + vuln digest engine. Single binary, zero external deps — runs on first boot with a mock feed, with clearly marked slots to plug in the real feed |
| [**HookShield**](https://github.com/rootwithkhandal/HookShield) | Python | Real-time endpoint detection — process, file-hash, keyboard-hook, network, clipboard, and startup monitoring, with web dashboard and CLI |
| [**Blackwall**](https://github.com/rootwithkhandal/Blackwall) | Python | Turns a Linux box into a mini SOC — live packet capture (Scapy), rule-based + IsolationForest ML anomaly detection, immutable decision logging, webhook alerts, Streamlit dashboard |
| [**Wazuh SIEM Lab**](https://github.com/rootwithkhandal/wazuh-n8n-integrations) | Wazuh · n8n | Centralized log monitoring with custom rules for privilege escalation & file-integrity monitoring, n8n-automated alerting |
